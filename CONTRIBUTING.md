# Contribuer a Dourou

## Stack technique

- **TypeScript** en mode strict
- **Expo Router** pour la navigation basee sur les fichiers (`app/`)
- **React Contexts** pour la gestion d'etat (`contexts/`)
- **Supabase** pour le backend (schema dans `supabase/schema.sql`)
- **i18n** : traductions dans `i18n/locales/` (fr.json est la langue principale)
- **Style** : configuration ESLint dans `eslint.config.js`

## Demarrage

```bash
npm install
npx expo start
```

## Contribuer

1. Fork le projet
2. Creez une branche (`git checkout -b feature/ma-feature`)
3. Commitez vos changements
4. Ouvrez une Pull Request

Merci pour vos contributions !
